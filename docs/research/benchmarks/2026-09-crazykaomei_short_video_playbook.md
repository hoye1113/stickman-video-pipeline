## 一、核心战略背景与自媒体闭环哲学

### 1.1 破局：从高昂试错成本到零边际成本
在传统 AIGC 视频创作流程中，单条高质量视频成本动辄数十至数百元（Midjourney、Runway Gen-3、Kling AI 等）。高昂的资金与心理试错成本常常导致创作者在反复权衡中磨灭灵感。

@CrazyKaomei 提出的破局核心在于**“一人可落地的「AI + 自媒体」最小阻力路径”**：
- 借助消费级权益（如极低成本的 Google One AI Premium PRO 会员），依托 Google Flow 原生通道，获取每月高额官方视频点数与大模型能力，打通**零边际成本的生成通路**。
- **底层认知**：
  > “你占到了一个入口，不等于你拥有了作品。用不起来的便宜，依然是昂贵的浪费。别把会员当主角，它只是一声开门声。真正要做的是打磨出一套属于你自己的内容生产闭环。”

## 二、生产降本杀手锏：两阶段资产生成法 (Two-Stage Asset Generation)

@CrazyKaomei 验证的最稳健、成本最低的图文/动态漫短视频生产流程是**“两阶段生成法”**：

```text
┌─────────────────────────────────────────────────────────────┐
│ 【阶段一：静态构图与人设锚定】                                │
│ Nano Banana 2 (Google Flow 内置，0 积分 / 无限量免费)        │
│ 作用：锁定角色一致性、背景光影、景深与构图（每次输出 4 张选优）  │
└──────────────────────────────┬──────────────────────────────┘
                               │ 选定最佳关键帧图片
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 【阶段二：首尾帧驱动的微动视频生成】                          │
│ Google Flow (Image-to-Video / First Frame Input)            │
│ 作用：以阶段一图片为首帧输入，赋予 10 秒自然运镜与肢体动作      │
│ 成本收益：废片率降低 90%，相比纯 Text-to-Video 盲猜省下海量积分 │
└─────────────────────────────────────────────────────────────┘
```

### 为什么该方案高度契合“动态漫”与“PPT 故事视频”？
1. **彻底解决角色形变（Consistency Problem）**：纯文本生视频每段都在盲盒抽奖；而通过 Nano Banana 2 垫图作为首帧（First Frame），模型基于确定性的空间与人物骨骼进行外推，人物面部、服装与画风完全稳定。
2. **零成本前期试错**：Nano Banana 2 在 Flow 内生成静态图 **0 消耗**，可以在不花 1 点视频积分的情况下，先将全篇 10~20 张漫画画格/幻灯片全部定稿。
3. **分镜级独立渲染**：在 Storyboard Studio 中，单张卡片独立渲染，彻底解决单会话多轮迭代时长累加崩溃问题。

## 三、行业精选开源项目与实践案例拆解

在 @CrazyKaomei 推荐的无露脸（0-face）AI 视频生产生态中，以下项目与案例具有极高的直接借鉴价值：

### 1. 手绘故事生成器 (`Hand-Drawn Story Generator` by @GeekCatX)
- **形式**：中文长文本故事输入 ➔ 自动拆解并生成 20+ 个漫画画格（Panel） ➔ 通过 Remotion 驱动动态推拉、分镜切换与动效。
- **借鉴点**：
  - 高度契合“看了一场漫画，听了一场故事”的听感与观感；
  - 核心并不依赖重度 3D 渲染，而是依靠“高信息量分镜画格 + 节奏紧凑的推拉运镜（Ken Burns 效果）”；
  - 极适合作为 `presets/comic_story` 的低算力备选方案（静态图 + 代码动效，几乎 0 视频算力开销）。

### 2. 呼吸感国风画卷 (`Breathing Chinese Painting` by @Hamburgerai 蛋黄堡)
- **形式**：4 张主题静态插画 + 4 句国风诗词/短句 + 微弱呼吸感运镜（Slow Zoom & Pan） + 环境氛围音效 + 精准时间戳字幕。
- **借鉴点**：
  - 极简极致的视听杠杆：极小的生成成本，凭借出色的环境音效和微动效，呈现出电影般的静谧情绪价值；
  - 证明了“视频不一定需要全动态打斗”，舒缓且富有呼吸感的慢运镜在知识科普、情感共鸣类短视频中完播率奇高。

### 3. 商业手绘讲解词提示词库 (`kaomei/hand-drawn-video-prompts`)
- **来源**：[`https://github.com/kaomei/hand-drawn-video-prompts`](https://github.com/kaomei/hand-drawn-video-prompts)
- **核心特色**：
  - 统一的 Q 版商业手绘科技/知识人物 Prompt 模板；
  - 包含人物特征锚点（Locked Avatar Schema）、纯白/纯黑极简背景控制、高饱和度点缀色彩；
  - 杜绝画面中出现随机垃圾文字（No Random Text Contract）。

### 4. 26 亿播放量 UGC 操盘体系 (Lucas Patiri Framework)
- **来源**：Lucas Patiri 分享的短视频流水线与预检清单（Twitter: `2101584386990964995`）。
- **核心转化漏斗**：
  - `0 ~ 1s`：**生死 Hook（Life-or-Death Hook）**。直切最刺痛人心的冲突点或行动视觉，禁止任何客套、片头或自我介绍；
  - `1 ~ 5s`：**大白话直击痛点（Pain Point Plain English）**。用观众听得懂的日常语言界定困境；
  - `5 ~ 20s`：**场景化机制与解法展开（Scenario-based Solution）**。通过具象画面解释“为什么会这样”、“破局关键在哪里”；
  - `20 ~ 30s`（或尾声）：**精准有力召唤行动（Sharp CTA）**。
- **预检门禁（Pre-flight QA Gate）**：
  - 统计显示：前 3 秒跑题或画面乏力，会导致完播率直接产生 **4.2 倍断崖式下跌**；
  - 必须在正式渲染前进行剧本与画面预审。

### 5. 单人月入 $78k AI Agency 多智能体架构 (DeRonin Architecture)
- **来源**：DeRonin 分享的单兵 AI 机构运作范式（Twitter: `2101951648235143396`）。
- **借鉴点**：
  - 坚持将“创意规划、脚本打磨、资产生成、后期剪辑”拆分为专能智能体；
  - 流程严格流水线化（Pipeline），人类只在关键门禁（Review Gates）签字放行，其余工序自动化流转。

## 四、动态漫画与图文视频的视觉及字幕工业规范

在动态漫、PPT 故事与手绘图文场景中，字幕与构图的阅读体验直接决定转化率：

### 1. 字幕标准：白字黑边（White Text + Black Outline）
- **痛点**：在动态漫画或手绘插画中，背景颜色丰富且存在大量线条与明暗交替，纯白字幕在亮底不可见，纯黑字幕在暗底不可见。
- **行业工业标准**：**白色文字 + 2~3px 纯黑外描边**：
  ```ini
  ; FFmpeg libass / SRT 核心样式配置
  PrimaryColour=&H00FFFFFF    ; 纯白文字
  OutlineColour=&H00000000    ; 纯黑外描边
  Outline=2.5                 ; 描边宽度
  BorderStyle=1
  Shadow=1                    ; 适度阴影增强层次
  ```
- **效果**：无论背景是纯黑、纯白还是复杂线条漫画格，字幕文字均清晰锐利，截屏保留度与完播体验极佳。

### 2. 画幅选型策略：4:3 黄金故事画幅
- **为什么不是 9:16 或 16:9？**
  - **4:3（学院比例/复古漫画比例）**：是图文、漫画与 PPT 分镜的最舒适比例。它在手机竖屏（全屏居中、上下留黑放标题）或者 PC 横屏（B站/YouTube）均具有极高兼容性；
  - 若需要发布至纯竖屏平台（抖音/小红书），可采用 4:3 居中 + 顶部吸睛大标题 + 底部字幕的安全区构图，避免人物被平台右侧互动图标遮挡。

### 3. 画面无文本契约（No Visual Text Contract）
- 在提示词中必须硬性约束：严禁画面出现任何生成的乱码文字、拟声词（除非特定漫画拟声词）、对话气泡或对话框；
- 故事叙述全部由高保真双语字幕 + 纯净旁白语音承担，画面保持干净电影级画质。

## 五、对本项目 `comic_story` 架构与未来图文视频的落地映射

结合 @CrazyKaomei 的方法论，我们对项目现有架构提出如下具体升级映射：

| 关键阶段 | 火柴人流程 (stickman) | 动态漫画/图文故事流程 (comic_story) | 收益与保障 |
|---|---|---|---|
| **前期策划** | 心理学机制检索 + 18 镜分镜 | **Lucas Patiri 痛点故事 + 角色锚定卡 (Avatar Lock)** | 故事感与代入感更强 |
| **画面资产生成** | 直接写提示词生 18 段视频 | **两阶段生成：Nano Banana 2 生 0 成本漫画格 ➔ 首尾帧驱动态漫** | 零积分试错，人物完全一致 |
| **动效实现** | 纯模型端到端视频生成 | **双轨模式：重要镜头 Flow 微动视频，过渡镜头代码 Ken Burns 运镜** | 极大节省视频积分，生产效率提升 3 倍 |
| **字幕与排版** | 双语字幕 + 居中下移 | **白字黑边 + CJK 字体 + 移动端 55%~75% 黄金安全区** | 复杂插画背景下 100% 清晰可读 |
| **安全审查** | 严格执行 `prompt_safety_policy.md` | 同样执行敏感词过滤，杜绝暴力与封禁风险 | 平台 0 拦截 |
